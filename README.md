# 無料食事イベント台帳

東京都内中心の「無料で参加でき、夕方以降に懇親会・Networking・Reception等があるイベント」を整理する台帳です。

## 公開ページ

https://rensei11.github.io/01-event/

## 現在のファイル構成

- `index.html`：本番台帳。2か月カレンダー、参加予定、参加記録、イベント編集、新規追加・削除等の画面
- `イベント一覧.json`：イベント名、日付、会場、参加条件、評価、夜の内容、公式URLなどの実データ
- `引き継ぎ.md`：ChatGPT等のAI向けの短い入口
- `現在状況.md`：現在の版・未解決・調査の正本を短く確認する入口
- `調査知識.md`：過去チャットから残した恒久的な判断基準・失敗例・実地知識
- `調査方法.md`：空白ホール等を含む深掘り検索の具体手順
- `現在の仕様.md`：UI・終了処理・データ運用などの詳細仕様
- `README.md`：この案内板
- `site/chunk0.txt` ～ `site/chunk5.txt`：旧版HTMLの退避用。現在の公開ページでは使用しない

## 更新するとき

本番台帳の通常操作はページ自身からCloudflare Worker経由でGitHubへ確定保存します。

- 「行く／興味あり／行かない」
- 複数日イベントの来場予定日
- 高評価／中評価／低評価
- イベント編集・日付変更
- 新規イベント
- イベント削除
- 終了処理・記録修正

通信失敗時だけブラウザに未保存分を残し、画面上部の「GitHubへ保存」から再送できます。

旧 `site/chunk*.txt` は、移行直後の復旧用として当面残しています。正常運用を確認するまでは削除しません。
