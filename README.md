# 無料食事イベント台帳

東京都内中心の「無料で参加でき、夕方以降に懇親会・Networking・Reception等があるイベント」を整理する台帳です。

## 公開ページ

https://rensei11.github.io/chatgpt-test/

## 現在のファイル構成

- `index.html`：表示画面、3か月カレンダー、参加予定チェック、除外チェック等のプログラム
- `イベント一覧.json`：イベント名、日付、会場、参加条件、評価、夜の内容、公式URLなどの実データ
- `引き継ぎ.md`：ChatGPT等のAI向け案件説明書
- `README.md`：この案内板
- `site/chunk0.txt` ～ `site/chunk5.txt`：旧版HTMLの退避用。現在の公開ページでは使用しない

## 更新するとき

通常は `イベント一覧.json` のイベントデータだけを更新します。

表示方法やチェック機能、カレンダーを変更するときだけ `index.html` を変更します。

旧 `site/chunk*.txt` は、移行直後の復旧用として当面残しています。正常運用を確認するまでは削除しません。
